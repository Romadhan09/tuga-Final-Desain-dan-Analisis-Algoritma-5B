Algoritma String Matching

Perbandingan algoritma yang digunakan dalam sistem pencarian

KMP (Knuth-Morris-Pratt)

Algoritma yang menggunakan informasi dari pattern untuk menghindari perbandingan ulang yang tidak perlu.

  • Kompleksitas: O(n + m)
  • Preprocessing pattern
  • Tidak mundur pada teks
Best Case: O(n) Worst Case: O(n + m)

Boyer-Moore

Algoritma yang memulai pencocokan dari kanan ke kiri dan menggunakan dua aturan: bad character dan good suffix.

  • Kompleksitas: O(n/m) - O(nm)
  • Cocok untuk pattern panjang
  • Skip karakter efisien
Best Case: O(n/m) Worst Case: O(nm)

Brute Force

Algoritma sederhana yang membandingkan pattern dengan setiap posisi pada teks secara berurutan.

  • Kompleksitas: O(nm)
  • Mudah diimplementasi
  • Tidak perlu preprocessing
Best Case: O(n) Worst Case: O(nm)

Tentang Sistem

Implementasi Algoritma String Matching untuk Sistem Pencarian Tempat Wisata di Indonesia Berbasis Web

Sistem ini merupakan implementasi dari beberapa algoritma string matching yang digunakan untuk mencari tempat wisata di Indonesia. Dataset yang digunakan adalah "Tourism with ID & Ratings" dari Kaggle.

Dataset Lengkap

Berisi data tempat wisata di Indonesia dengan informasi nama, kota, kategori, deskripsi, dan rating.

3 Algoritma String Matching

KMP, Boyer-Moore, dan Brute Force untuk perbandingan performa pencarian.

Analisis Performa

Menampilkan waktu eksekusi dan jumlah perbandingan dari setiap algoritma.

Filter Pencarian

Filter berdasarkan kategori, kota, dan rating untuk hasil yang lebih spesifik.
